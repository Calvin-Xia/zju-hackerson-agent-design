## 2. 处理流程与算法

```
教材解析 → 知识点抽取 → 语义对齐 → 整合决策 → 决策应用 → 压缩比控制
```

| 阶段 | 关键实现 |
|------|----------|
| 知识点抽取 | 章节超长时按段落硬切分片，受 `LLM_CONCURRENCY` 约束并发抽取；JSON 解析失败自动重试一次；节点按归一化名称合并并累计频次 |
| 语义对齐 | 分块计算余弦相似度矩阵 → 分层判定（同名直接等价 / 高相似度直接判定 / 灰区可选 LLM 批量复核）→ **一对一贪心匹配**，保证每个知识点最多与另一本教材的一个知识点配对 |
| 整合决策 | 规则判定：`merge`（各有独有信息，描述取并集）/ `keep`（保留更完整一侧）/ `remove`（描述已被完全覆盖） |
| 决策应用 | 合并描述、累加跨教材频次、清理被删节点上的悬空关系 |
| 压缩比控制 | 三级递进：合并 → 抽取式摘要（按重要度分配字数预算）→ 按重要度丢弃低价值节点（始终至少保留一个节点） |

**一对一匹配的价值**：若不限制配对数量，一个知识点可能与多本教材的多个节点
同时配对，进而在"决策应用"阶段被多条决策反复删除，造成连锁误删与重复计数。
当前实现保证每个节点最多参与一条决策。

## 6. 压缩比达成分析

目标为 `压缩比 = 整合后字数 / 原始总字数 ≤ 30%`，本次实测 **29.2%**。

三级策略的贡献：

1. **合并**：7 组跨教材重复知识点合并描述，直接减少重复字数；
2. **摘要**：对 15 个描述较长的知识点按重要度分配字数预算做抽取式摘要，
   保住全部知识点结构（不是简单粗暴地砍掉大半内容）；
3. **筛选**：仍超预算时，按重要度从低到高丢弃 31 个节点。

设计上的两个保底约束：

- **跨教材共享概念受保护**：整合后频次 ≥ 2 的知识点（即在多本教材中都出现的
  核心概念）不参与丢弃，优先保留完整描述；
- **至少保留一个节点**：宁可略微超出压缩比，也不产出空白知识图谱。

## 7. 问答验证（RAG）

对建立索引后的知识库提问，验证"回答附带原文引用"：

- 提问「细胞膜的结构和功能是什么？血液由哪些成分组成？」
  → 检索 5 个片段（最高相似度 0.317），回答以 `[2][3][4][5]` 标注来源，
  并在引用列表给出教材、章节、页码与相似度；
- 提问不在知识库范围内的问题（如「如何用 Python 实现快速排序算法？」）
  → 检索结果低于相关性阈值，直接返回「当前知识库中未找到相关信息」，
  **不调用大模型、不编造答案**；
- 多本教材描述同一内容时，只保留最相关的一段，并记录"相同内容还出现于"。

## 8. 结论

### 8.1 达标情况

| 赛题要求 | 实现情况 |
|----------|----------|
| 多格式教材解析 | ✅ PDF / Markdown / TXT / DOCX / XLSX |
| 知识图谱可视化 | ✅ 力导向图，支持按分类/按教材着色、搜索、拖动、全屏 |
| 跨教材整合，压缩比 ≤ 30% | ✅ 实测 **29.2%** |
| 整合过程可解释 | ✅ 31 条决策均附带中文理由，并提供压缩比/字数/节点/关系四维统计 |
| RAG 问答附带原文引用 | ✅ 回答标注 `[n]`，引用包含教材/章节/页码/相似度 |
| 多轮对话优化整合方案 | ✅ 上下文持久化，支持按对话历史生成回复与后续操作建议 |

### 8.2 工程可靠性

- **89 → 90 个后端测试用例**覆盖对齐、决策、压缩、分块、RAG、存储与配置；
- 整合流程**确定性**（默认不调用 LLM），秒级完成且结果可复现；
- 任务状态、知识图谱、对话历史的落盘均为**原子写入**（临时文件 + 原子替换），
  进程中断不会留下截断的 JSON；
- 维度/后端变化时**拒绝加载不兼容的旧向量索引**，避免"维度相同但语义不同"的脏数据被误用。

### 8.3 局限与后续改进

1. **嵌入质量受环境影响**：当前环境使用 hashing 降级后端，语义对齐偏字面匹配；
   在能加载 `paraphrase-multilingual-MiniLM-L12-v2` 的环境中召回质量会更好；
2. **灰区复核默认关闭**：`ALIGNMENT_USE_LLM=true` 可开启 LLM 复核，
   代价是整合耗时随候选对数量线性增长；
3. **规模上限**：全量对齐是 O(n·m) 的相似度矩阵计算（已分块限制峰值内存），
   面向超大教材库时可引入向量索引（FAISS IVF/HNSW）先做近似召回；
4. **人工干预**：当前支持修改知识点/关系，后续可扩展为"人工覆写某条整合决策并重新应用"。
