# 接口文档

后端基于 FastAPI，所有接口挂在 `/api` 前缀下。开发环境前端通过 Vite 代理
（`/api` → `http://localhost:8001`）访问；生产环境由后端直接托管前端构建产物。

交互式文档：

- Swagger UI：`http://localhost:8001/docs`
- OpenAPI JSON：`http://localhost:8001/openapi.json`

## 通用约定

- 请求/响应均为 UTF-8 JSON（文件上传除外，使用 `multipart/form-data`）。
- 错误响应统一为 `{"detail": "错误说明"}`，并配合语义化状态码：
  `400` 参数问题、`404` 资源不存在、`409` 状态冲突（如任务未完成、图谱损坏）、
  `413` 文件过大、`502` 上游大模型调用失败。
- 耗时操作（解析、抽取、整合、建索引）均为**异步任务**：接口立即返回 `task_id`，
  再通过对应的 `status` 接口轮询进度（`progress` 为 0–100 的百分比）。

## 接口总览

| 接口 | 说明 | 分组 |
|------|------|------|
| `POST /api/dialogue/chat` | 发送消息（多轮对话） | dialogue |
| `POST /api/dialogue/feedback` | 提交对整合决策的反馈 | dialogue |
| `GET /api/dialogue/history/{conversation_id}` | 获取对话历史（`limit` 默认 200） | dialogue |
| `DELETE /api/dialogue/history/{conversation_id}` | 清空对话历史（内存 + 磁盘） | dialogue |
| `GET /api/files/` | 列出所有教材及其解析/图谱状态 | files |
| `DELETE /api/files/{file_id}` | 删除教材及其派生数据（解析结果、图谱、向量） | files |
| `GET /api/health` | 健康检查（含嵌入后端与向量库状态） | system |
| `GET /api/integration/alignment/{task_id}` | 语义对齐明细（候选对、等价对、判定依据） | integration |
| `GET /api/integration/decisions/{task_id}` | 整合决策列表 | integration |
| `GET /api/integration/graph/{task_id}` | 整合后的知识图谱 | integration |
| `POST /api/integration/merge` | 启动跨教材整合 | integration |
| `GET /api/integration/statistics/{task_id}` | 整合统计（含压缩比与是否达标） | integration |
| `GET /api/integration/status/{task_id}` | 整合任务进度 | integration |
| `GET /api/integration/tasks` | 最近的整合任务列表 | integration |
| `POST /api/kg/extract` | 触发知识点抽取（`force=true` 可重抽） | knowledge-graph |
| `GET /api/kg/graph/{file_id}` | 获取单本教材的知识图谱（`all=true` 全量） | knowledge-graph |
| `DELETE /api/kg/graph/{file_id}` | 删除知识图谱 | knowledge-graph |
| `PUT /api/kg/graph/{file_id}/node/{node_id}` | 修改知识点 | knowledge-graph |
| `PUT /api/kg/graph/{file_id}/relation` | 修改关系 | knowledge-graph |
| `GET /api/kg/graphs` | 列出所有知识图谱的概要 | knowledge-graph |
| `GET /api/kg/status/{file_id}` | 抽取任务进度 | knowledge-graph |
| `GET /api/parse/status/{file_id}` | 解析状态 | parse |
| `POST /api/parse/{file_id}/parse` | 重新解析 | parse |
| `POST /api/rag/index` | 建立向量索引（后台任务） | rag |
| `DELETE /api/rag/index` | 清空索引（内存 + 磁盘） | rag |
| `GET /api/rag/index/status/{task_id}` | 建索引任务进度 | rag |
| `GET /api/rag/no-answer-text` | 统一的「未找到相关信息」文案 | rag |
| `POST /api/rag/query` | 基于教材内容提问 | rag |
| `GET /api/rag/status` | 索引状态（片段数、已索引教材、嵌入后端） | rag |
| `POST /api/upload/` | 上传教材（`multipart/form-data`，字段名 `file`） | upload |

## 典型调用流程

### 1. 上传 → 解析

```bash
curl -X POST http://localhost:8001/api/upload/ -F "file=@生理学.pdf"
# => {"file_id":"<uuid>","filename":"生理学.pdf","size":123,"message":"上传成功，已开始解析"}

curl http://localhost:8001/api/parse/status/<uuid>
# => {"file_id":"<uuid>","status":"completed","chapter_count":6,"total_chars":1060,...}
```

### 2. 抽取知识图谱

```bash
curl -X POST http://localhost:8001/api/kg/extract \
     -H "Content-Type: application/json" \
     -d '{"file_id":"<uuid>","force":false}'

curl http://localhost:8001/api/kg/status/<uuid>
# => {"status":"completed","progress":100.0,"total_nodes":42,"total_relations":48}
```

### 3. 跨教材整合

```bash
curl -X POST http://localhost:8001/api/integration/merge \
     -H "Content-Type: application/json" \
     -d '{"textbook_ids":["<uuid-1>","<uuid-2>"]}'
# => {"task_id":"integration_xxxxxxxx","message":"已开始整合 2 本教材"}

curl http://localhost:8001/api/integration/statistics/integration_xxxxxxxx
# => {"compression_ratio":0.292,"is_within_limit":true,"max_compression_ratio":0.3,...}
```

### 4. 建立索引并提问

```bash
curl -X POST http://localhost:8001/api/rag/index \
     -H "Content-Type: application/json" \
     -d '{"file_ids":["<uuid-1>","<uuid-2>"]}'
# => {"task_id":"index_xxxxxxxx",...}

curl -X POST http://localhost:8001/api/rag/query \
     -H "Content-Type: application/json" \
     -d '{"question":"细胞膜的结构和功能是什么？"}'
# => {"answer":"... [1][2] ...","citations":[{"textbook":"...","chapter":"...","content":"...","relevance_score":0.35}],...}
```

## 字段说明（要点）

### 教材文件 `GET /api/files/`

| 字段 | 含义 |
|------|------|
| `parse_status` | `pending` 排队中 / `parsing` 解析中 / `completed` 已完成 / `failed` 失败 |
| `has_graph` | 是否已抽取知识图谱 |
| `error_message` | `failed` 时的失败原因 |

### 整合统计 `GET /api/integration/statistics/{task_id}`

| 字段 | 含义 |
|------|------|
| `compression_ratio` | 压缩比 = 压缩后字数 / 原始总字数（赛题要求 ≤ 0.30） |
| `is_within_limit` | 是否满足压缩比要求 |
| `original_node_count` → `compressed_node_count` | 知识点数量变化 |
| `merge_count` / `keep_count` / `remove_count` | 三类决策的数量 |
| `condensed_node_count` / `dropped_node_count` | 被摘要压缩 / 被丢弃的知识点数 |
| `alignment_candidates` / `aligned_pair_count` | 语义对齐候选对与最终等价对数量 |

### RAG 问答 `POST /api/rag/query`

| 字段 | 含义 |
|------|------|
| `answer` | 回答正文，使用 `[n]` 标注来源编号 |
| `citations` | 引用列表（`textbook`/`chapter`/`page`/`content`/`relevance_score`/`duplicate_sources`） |
| `retrieved_count` | 通过相关性过滤的片段数 |
| `top_score` | 最高相似度 |

检索不到足够相关的内容时返回统一的 `当前知识库中未找到相关信息`，且 `citations` 为空。
